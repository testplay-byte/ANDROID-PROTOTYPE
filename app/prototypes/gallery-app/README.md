# Gallery App (Bauhaus)

A geometric-modernist gallery prototype built on proto-kit with the
**Bauhaus** design language: the red/blue/yellow triad as solid blocks,
2px ink borders, sharp corners, no shadows, uppercase weight-900 headings.

## Screens (4)

1. **Exhibitions** — pure CSS geometric poster cards + TICKETS buttons
2. **Collection** — filter chips + geometric art grid with favorites
3. **Visit** — hours, address, ticket steppers, BOOK → stamped confirmation
4. **Settings** — theme, guided tours, newsletter toggles

## Interactions

Ticket toggle, category filtering, favorite hearts, ticket steppers with a
live total and booked confirmation, dark-theme toggle, swipe between tabs.
