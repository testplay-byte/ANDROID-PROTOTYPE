# Linie (Bauhaus)

A metro planner — network map, journey planner, live departures, ticket
wallet — in the repo's second bauhaus demo. Red primary, blue/yellow
accents, 2px ink borders on every box, zero shadows, near-square corners.
`style="bauhaus"`, `DeviceThemeProvider storageKey="linie-theme"`.

**Screens:** Netz (SVG map, line isolation, station select), Route
(planner + vertical diagram), Abfahrt (live countdowns), Ich (routes,
passes, theme).

See `navigation.md` for the bauhaus discipline notes.
