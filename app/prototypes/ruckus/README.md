# Ruckus (Neo-brutalism)

A DIY live-music gig guide — lineup, bands, rooms and a ticket wallet — in
the repo's second brutalism demo. 0px radius, 2-3px ink borders, hard
offset shadows, marquee tickers, poster type and flat yellow/orange-red
blocks. `style="brutalism"`, `DeviceThemeProvider storageKey="ruckus-theme"`.

**Screens:** Gigs (numbered lineup → gig detail with ticket purchase),
Bands (generative covers + follow), Rooms (capacity meters), Me (ticket stubs,
alerts, theme).

See `navigation.md` for the brutalism discipline notes.
