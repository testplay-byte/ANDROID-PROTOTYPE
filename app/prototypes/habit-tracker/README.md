# Habit Tracker (Minimalism)

A monochrome habit-tracking prototype built on proto-kit with the
**Minimalism** design language: hairline borders, generous whitespace,
ink as the only "color". `--color-error` is the single accent, used only
for the destructive reset.

## Screens (4)

1. **Today** — day-progress ring + habit checklist with animated streaks
2. **Stats** — weekly monochrome heatmap, completion %, best streak
3. **Habits** — list with inline add/edit/delete form
4. **Settings** — theme, week start, reminders, reset with confirm

## Interactions

Check/uncheck habits (streak animates), inline habit editor, Mon/Sun week
start, dark-theme toggle, reset data with confirm, swipe between tabs.
