# Simmer — prototype

Claymorphism recipes & cooking companion: puffy shadow-layered surfaces,
generative CSS dish art, a week's meal plan that derives its own
shopping list, and one chunky clay kitchen dial.

- **Style:** Clay (`--shadow-2` puffy idle / translateY + `--shadow-inset` pressed dough), pastel-but-saturated palette, chunky radii, zero borders. Light theme re-derived for ≥4.5:1 text contrast.
- **Screens (5):** Cook (home hero + picks rail), Find (search + category chips + grid), Recipe detail (sticky clay header, live serving stepper, press-in method blobs), Plan (5 day cards + picker sheet + aisle-grouped checkable shopping list), Kitchen (clay countdown dial, favorites, pantry pucks, theme).
- **Key interactions:** Simmer-now arms the dial from any recipe; steps/checks/plan/favorites/pantry persist (`simmer-*`); pressed-dough feedback on everything; staggered entrances; reduced-motion block.

Live: https://testplay-byte.github.io/ANDROID-PROTOTYPE/prototypes/simmer/
