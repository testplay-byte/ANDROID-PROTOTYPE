# Streetwear Store — prototype

Neo-brutalist streetwear shop for the fictional "DROP 07" label: thick
2px borders, hard offset shadows, zero radius, yellow primary.

- **Style:** Brutalism (`--border-w` 2px + `--shadow-1/2` hard offsets on every container, radius 0, uppercase 900 headings).
- **Screens (4):** Shop, Product detail (pushed), Cart, Settings.
- **Key interactions:** category chip filtering, quick-add + detail add-to-cart with size/qty, live "Cart (n)" nav badge, checkout confirmation state, light/dark theme, USD/EUR/GBP re-pricing.

Live: https://testplay-byte.github.io/ANDROID-PROTOTYPE/prototypes/streetwear-store/
