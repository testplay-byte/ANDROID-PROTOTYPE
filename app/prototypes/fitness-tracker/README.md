# fitness-tracker

An Apple HIG style fitness tracker prototype — three SVG activity rings with
a weekly day selector, workout types that launch an inline session with a big
circular progress ring and live timer, a profile with stats grid and
achievement badges, and iOS inset grouped settings (theme segmented control,
units, weekly goal stepper). Built on `src/proto-kit/` (DeviceFrame
`style="hig"`, BottomNav `variant="tabbar"`, TopBar `variant="center"`).

## Screens

1. **Activity** — activity rings (move/exercise/stand), day selector, stat cards
2. **Workouts** — workout list → inline session timer (start/pause/reset)
3. **Profile** — avatar header, stats grid, achievement badges
4. **Settings** — appearance (Light/Dark), units (km/mi), weekly goal stepper, About
