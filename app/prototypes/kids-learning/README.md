# Kids Learning — prototype

Claymorphism learning game for preschoolers: puffy pastel surfaces, star
rewards, and a badge shelf.

- **Style:** Clay (`--shadow-2` puffy idle / `--shadow-inset` pressed), pastel palette, chunky 800+ type.
- **Screens (4):** Home, Play, Awards, Settings.
- **Key interactions:** subject tiles → preselected game, squish/star-fly/shake answer feedback, round summaries, badge unlock sheet, night mode, reset stars with confirm.

Live: https://testplay-byte.github.io/ANDROID-PROTOTYPE/prototypes/kids-learning/
