# Chat App — prototype

Flat Design 2.0 messenger: teal + coral color blocks, geometric rows,
zero shadows.

- **Style:** Flat (`--shadow-*: none`), saturated teal primary, coral secondary, depth via surface tones only.
- **Screens (4):** Chats, Chat Detail (pushed), Calls, Settings.
- **Key interactions:** search with the on-screen keyboard, chat threads with day dividers + typing indicator + 1s canned auto-replies, "Calling..." overlay, theme/notifications/read-receipt toggles.

Live: https://testplay-byte.github.io/ANDROID-PROTOTYPE/prototypes/chat-app/
