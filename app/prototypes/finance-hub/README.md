# Finance Hub — prototype

IBM Carbon-style banking app: flat layer surfaces, 1px borders, 0px
radius, IBM blue primary, tabular-nums money.

- **Style:** Carbon (`--shadow-*` = none, structure via 1px borders and layer tones, 100–150ms motion, no bounce).
- **Screens (4):** Overview, Activity, Cards, Settings.
- **Key interactions:** 12-month spending bar chart with peak highlight, ALL/IN/OUT filters, expandable transaction details with status tags, snap-scroll card deck with per-card freeze toggles and number reveal, dark/light theme.

Live: https://testplay-byte.github.io/ANDROID-PROTOTYPE/prototypes/finance-hub/
